## 状态定义

| 状态 | 含义 |
| --- | --- |
| 未开始 | 无判据、无证据 |
| 进行中 | 有判据但阈值仍为占位，或证据不完整 |
| **已接入** | 判据明确、阈值有实测来源、证据可复现、owner 具名、进入某一环的门禁 |

## 起步顺序（P0 止血）

只先填这三行：`D0-1`、`D5-1`/`D5-2`、`D5-6`。它们决定"现有数据可不可信"和"最坏能坏到什么程度"。
