# 检查单 02：风险与测试策略（S4）

## 风险识别
- [ ] 已从需求契约（不变量/异常/副作用）逐条推导候选风险
- [ ] 已从技术契约（gap/不可观察点/异步边界）推导候选风险
- [ ] 已纳入历史缺陷的复发倾向
- [ ] 已纳入三类 AI 特有风险：非确定性、漂移、注入与越权

## 打分与分档
- [ ] 每条风险有 I/L/D 三个分值与计算出的 RPN
- [ ] 分档规则已写入《测试策略》，不是临场判断
- [ ] 每条降档有理由、接受人与复评日期
- [ ] 没有出现"这个我们一直没测过所以先跳过"

## 层级与方法
- [ ] 每条风险有且仅有一个主责层级
- [ ] 层级选择依据是"缺陷在哪一层最早最便宜最稳定地暴露"
- [ ] 方法选择有记录，且理由不是工具名或团队习惯
- [ ] AI 无标准答案的场景已选用变形测试或复合 Oracle
- [ ] 需要证明检测力的场景已安排变异测试
- [ ] 没有把大量分支覆盖堆到 E2E 层

## 不可行与残余
- [ ] 不可行组合已显式记录（不是悄悄不做）
- [ ] 每条残余风险有等级、替代措施、接受人、复评日期
- [ ] 《测试策略》中没有用"用例数量"作为质量判据

## 阈值
- [ ] 首次填写未直接设阈值，而是先安排 3–5 个周期的实测采集
- [ ] 已有阈值都标注了"基于 N 个周期实测"与复评日期
