# 检查单 08：生产事件回灌（Trace-to-Regression）

> 目标：每个逃逸缺陷在 5 个工作日内闭环。

## 捕获
- [ ] 完整 Trace / 输入 / 版本五要素 / 用户影响面已保存
- [ ] 已脱敏（含 Trace 与日志中的敏感字段）

## 复现
- [ ] 在测试环境稳定复现，并记录复现率 M/N
- [ ] 非确定性缺陷未写成"偶现"，而是写 N 次中复现 M 次

## 归因
- [ ] 已定位到五层之一：输入数据 / 模型 Prompt / 检索工具 / 环境 / Scorer 阈值
- [ ] 无法区分时输出 `UNKNOWN` 并升级，未编造根因

## 回归
- [ ] 已补一条能**稳定变红**的回归用例
- [ ] 该用例已并入对应 Gate 层
- [ ] 已用变异验证这条用例确实有检测力（不是只在这个 case 上绿转红）

## 反查
- [ ] 已反查同类风险还有哪些未覆盖
- [ ] 反查结果已补进风险登记册
- [ ] 已更新 Oracle / 数据集 / 攻击集

## 台账
- [ ] 已记入缺陷逃逸台账
- [ ] 已标注逃逸原因分类（未覆盖风险 / Oracle 不足 / 数据不代表 / 环境差异 / **已知但被 Waiver**）
- [ ] 已标注"本应被哪一层 Gate 拦下"

## 禁止
- [ ] 未出现"只修代码不补用例"
- [ ] 未出现"只补用例不验证检测力"
- [ ] 未出现"只处理这一个 case 不做同类反查"
