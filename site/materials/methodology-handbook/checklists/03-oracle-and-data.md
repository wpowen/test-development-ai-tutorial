# 检查单 03：Oracle 与测试数据（S5–S6）

## Oracle
- [ ] Oracle 在用例之前确定
- [ ] 每个关键条件的 Oracle 独立于被测实现
- [ ] 每个关键条件的 Oracle 独立于本次模型输出
- [ ] L5 语义层未被用于放行任何 blocker
- [ ] 关键金额/权限/状态/合规由 L4 规则或 L6 人工判定
- [ ] 无独立 Oracle 的条件已显式 `BLOCKED`，未用"人工目测"代替
- [ ] 若使用 LLM Judge：已先测人人一致性，再测 Judge 一致性
- [ ] 若使用 LLM Judge：已做位置/长度/风格/自偏好四类偏差探针
- [ ] Judge 版本已记录；更换后会重新校准

## 用例
- [ ] 每条用例能回答：覆盖哪条 risk、期望值来自哪个 Oracle、能杀死哪个变异
- [ ] 无法追溯到需求的用例已标 `EXPLORATORY`，未计入需求覆盖
- [ ] AI 生成用例已通过变异杀死率验证，不是直接合并
- [ ] 高风险条目的期望值已人工逐条复核

## 数据
- [ ] 每个数据集有来源、授权、脱敏方式与版本、保留期
- [ ] 无未脱敏真实个人信息 / 真实支付账号 / 生产密钥
- [ ] 切分先于调优；sealed holdout 已封存且开封次数在约定内
- [ ] 切片按业务风险划分，blocker 切片已声明
- [ ] 评测集含五类样本：正例/边界/负例/冲突缺失/越权攻击
- [ ] 期望拒答与期望截断样本已单独登记
- [ ] 已做污染检查（公开集训练污染、Prompt 示例泄漏、holdout 泄漏）
- [ ] 假名化数据已评估准标识符组合的再识别风险
