# 检查单 05：AI 系统专项

> 先用方法论 07.0 决策树判定类别，再跑对应小节。判据是"路径由谁决定"，不是产品命名。

## 通用（所有 AI 系统）
- [ ] 模型 ID、版本、参数已固定并记录（不使用浮动别名）
- [ ] Prompt 已版本化，含 Schema、eval、mutation（不是聊天记录）
- [ ] 重复运行 N≥5，报告分布而非单值
- [ ] 拒答与截断是显式状态，`finish_reason` 已被断言
- [ ] 上下文窗口边界、最大输出长度边界已测
- [ ] 结构化输出已做 Schema 校验，且未把它当成语义正确
- [ ] A/B 只改一个变量；两个锁定字段同时变化即标 `confounded`
- [ ] A/B 两侧缓存命中率一致或缓存已关闭
- [ ] 已测成本与延迟变化（单位成功成本）

## RAG 追加
- [ ] 语料版本与快照 ID 已冻结；重建索引视为新版本
- [ ] 分块策略作为受控变量，变更即重测
- [ ] 检索评测独立于生成评测（先证明检索没问题）
- [ ] 查询切片含：常见 / 长尾 / 歧义 / 无答案 / 越权
- [ ] **无答案样本已建**，正确行为是明确说明无法回答
- [ ] 引用存在性已自动校验
- [ ] 忠实度已单独度量（不等于"正确"）
- [ ] 不同身份检索到的集合不同；跨租户为 blocker
- [ ] 换嵌入模型/分块/索引参数后已全量重测

## Agent 追加
- [ ] Outcome / Step / Trajectory 三层**分别判定并分别报告**
- [ ] 未把一条黄金轨迹当唯一正确答案（写不变量+禁止副作用+必要检查点）
- [ ] 每个工具声明了 Schema、最小权限、副作用、幂等键、审批条件
- [ ] 写前授权链已在工具边界实现（不是在 Prompt 里请求）
- [ ] 测试在录制沙箱中进行，`assert_no_side_effect` 真实写入为 0
- [ ] 故障注入覆盖：不存在的工具、越界参数、错误身份、重复调用、缺前置步骤
- [ ] 攻击集覆盖直接注入**与间接注入**（污染文档/网页/邮件/工具返回）
- [ ] 报告区分"模型拒绝"与"授权层拒绝"
- [ ] 跨租户读取任一次出现即 blocker
- [ ] 预算护栏（迭代/时间/token/成本）生效并留下 `stop_reason`
- [ ] 已报告 pass@k **与** pass^k，并说明对用户承诺用哪个
- [ ] 人工确认次数、确认信息质量、默认值安全性已测（确认疲劳）
- [ ] Healer 未删除断言、未修改期望值、未跳过业务步骤
- [ ] Healer 候选修复在原业务变异下仍然失败

## Workflow / Worker 追加
- [ ] 状态机合法转换全覆盖，非法转换全部拒绝
- [ ] 同一 idempotency key 重复投递，副作用只发生一次
- [ ] 崩溃后从 checkpoint 正确恢复，不重复已提交副作用
- [ ] 死信条件与人工恢复路径已验证
- [ ] Handoff 目标错误时拒绝且下游权限不扩大
- [ ] 孤儿任务能被发现并告警
- [ ] 补偿与回滚动作可执行且可验证

## Serving 追加
- [ ] 负载模型含输入/输出 token 分布（不是固定长度）
- [ ] TTFT、TPOT/ITL、E2E 延迟分开报告
- [ ] 容量结论基于 Goodput，而非裸吞吐
- [ ] 阶梯加压找 SLO 拐点（不是找最大 QPS）
- [ ] 限流、超时、重试预算、熔断、降级、Fallback 已分别验证
- [ ] 降级路径的质量下限已定义并测量
- [ ] 冷启动首请求延迟已测
