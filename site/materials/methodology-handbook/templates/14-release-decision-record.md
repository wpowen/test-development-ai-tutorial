# 发布决定书

> 发布不是流水线绿灯，是一份署名决定。

```
版本            : <版本号> / <git sha>
变更摘要        : <一句话>
被测对象类别    : 传统 / LLM / RAG / Agent / Workflow / Serving

【本次只改变了什么】
  代码          : <sha 范围>
  模型          : <前> → <后>（未变则写 未变）
  Prompt        : <前> → <后>
  索引/分块     : <前> → <后>
  工具/权限     : <前> → <后>
  Scorer/阈值   : <前> → <后>

【证据】
  run_id 列表   : <id, id, id>
  报告路径      : <path>
  0/1/0 三段    : baseline exit <0> / fault exit <1> / repair exit <0>
  重复运行      : N=<n>，blocker 切片失败率区间 <[a, b]>

【门禁结果】
  Gate-1 : PASS / FAIL
  Gate-2 : PASS / FAIL
  Gate-3 : PASS / FAIL（Waiver: <W-id>）
  Gate-4 : PASS / FAIL

【剩余风险】（必填，"无"需说明为什么）
  R-<id>  <描述>  等级 <H/M/L>  接受人 <姓名>
  R-<id>  <描述>  等级 <H/M/L>  接受人 <姓名>

【发布方式】
  影子 <n> 天 → 金丝雀 <n>% × <n> 天 → 放量 → 全量
  各阶段进入条件：<…>

【回滚】
  触发条件      : ① S1/S2 缺陷 ② <切片> 失败率 > <阈值> ③ p95 > <阈值>
  回滚对象      : 模型 + Prompt + 索引 + 工具 + 阈值（必须成组）
  执行人        : <姓名/角色>      预计耗时：<分钟>
  演练记录      : <日期 / run_id>
  数据一致性处理: <说明>

【生产观察】
  指标与阈值    : <指标: 阈值>…
  持续评估节奏  : <见方法论 06 章 9.5.1>

【决定】
  决定          : 发布 / 有条件发布 / 不发布
  决定人        : <发布 owner 姓名>       日期：<YYYY-MM-DD>
  成熟度声明    : 本次证据等级 L<n>；未覆盖 L<n+1..5>
```
