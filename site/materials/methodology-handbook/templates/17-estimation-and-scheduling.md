# 估算与排期

## 1. 不要用的估算方式

- ✗ 用例条数 × 单条工时（用例数是结果不是输入）
- ✗ "上次也差不多这么久"（风险构成不同）
- ✗ 开发工时的固定百分比（与风险无关）

## 2. 按风险档位估算

```
测试投入 = Σ (各档位风险数 × 该档位单位投入)
```

| 档位 | 风险数 | 单位投入（本团队实测） | 小计 |
| --- | ---: | ---: | ---: |
| 关键 | | | |
| 高 | | | |
| 中 | | | |
| 低 | | | |
| **合计** | | | |

> **首次使用不要估算**：先实测一个完整需求批次的各档位耗时，第二个批次开始才用它估算。

### 单位投入构成参考

| 档位 | 构成 |
| --- | --- |
| 关键 | 契约化 + 独立 Oracle 设计 + 用例 + 变异 + 故障注入 + 人工复核 + 监控项 |
| 高 | 契约化 + Oracle + 用例 + 负例集 |
| 中 | 用例 + 边界 |
| 低 | 冒烟 |

## 4. 排期原则自查

- [ ] S1–S5 与开发**并行**，不是开发完再开始
- [ ] 变异与故障注入**未被压缩**
- [ ] 人工标注与复核已预留**等待时间**（非可压缩工程任务）
- [ ] 已显式留出 UNKNOWN 缓冲
