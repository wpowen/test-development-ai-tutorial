# 测试开发职业现实地图模板

选择最近一次真实但可脱敏的需求、发布或事故。先填写原流程，再决定 AI 放在哪一步。

| 字段 | 需要填写的内容 |
| --- | --- |
| 触发事件 | 为什么现在开始这项工作 |
| 输入与版本 | PRD、技术方案、接口、代码、数据、告警等 |
| 依赖 | 人、系统、权限、环境、时间窗口 |
| 必要工件 | 风险、策略、用例、脚本、报告、Trace、发布证据 |
| 下游消费者 | 谁会拿它做什么决定 |
| 失败成本 | 漏测、误报、延迟、数据损坏、合规或成本 |
| 当前基线 | 耗时、返工、缺陷逃逸、Flaky、定位时间 |
| AI 权限 | 允许读取什么、生成什么、执行什么 |
| 人工门禁 | 哪些决定不能交给 AI |
| 故障注入 | 怎样证明这套流程能发现已知坏结果 |
| 成功指标 | 提前发现、节省时间、降低误报或增加可审计性 |

完成后必须能沿着 `输入 → 行动 → 工件 → 决定 → 反馈` 讲清一条链。如果某一步只能靠公司内部资料确认，标记为 `INTERNAL-UNKNOWN`，并写出要访谈的人和要读取的文档。
