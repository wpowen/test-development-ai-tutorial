# Judge Card

> **judge 换版本 = 一次需要走变更评审的发布。** 没有卡片的 judge 不得进入任何门禁。

```
judge_id            : <judge-refund-v3>
用途范围            : <哪些切片允许自动评分>
模型与版本          : <provider>/<model>@<version>        ← 不得使用浮动别名
temperature         : <值>
其他采样参数        : <top_p / seed / max_tokens>
rubric 版本与全文   : <版本号 + 指向版本化文件的路径>

── 校准 ──────────────────────────────────────────────
校准日期            : <YYYY-MM-DD>
金标集 ID / 样本量  : <id> / <n>
标注员              : <姓名 ×2 或 ×3>
标注者间 κ（人–人） : <值>          ← 这是 judge κ 的上限
judge–human κ       : <值>          ← 只在人类共识样本上计算
Spearman            : <值>

── 偏置探针 ──────────────────────────────────────────
位置偏置（交换一致率）: <值>   构造：同一对候选交换顺序各跑一次
冗长偏置（加料后分差）: <值>   构造：同事实答案加入无关礼貌/解释文字
自偏好（同族–异族胜率差）: <值>  构造：同族与异族模型各生成一组等质量答案
事实错误穿透率       : <值>   构造：表达流畅但引用过期政策

── 权限边界 ──────────────────────────────────────────
允许自动评分        : <切片列表>
需要抽检            : <切片列表>
必须人工审批        : <切片列表>   ← 金额/权限/状态/合规必须在此
明确不使用          : <哪些判断禁止交给本 judge>

── 停用与回退 ────────────────────────────────────────
停用条件            : κ < <阈值>，或模型版本变化，或 rubric 变更
停用后动作          : judge 停用 → 回退人审 → 本轮所有下游分数标记无效
重校准频率          : <每月 / 换模型时>

owner               : <姓名/角色>
```

## 填写提醒

1. **先测人人一致性再测 judge**。κ_human 过低说明 rubric 有歧义，先改 rubric。
2. **judge 与 generator 必须不同模型族**，否则自偏好不可控。
3. **不要用 rubric 测本可以用断言测的东西**（金额、状态、权限、引用存在性）。
4. 分层策略：CI 门禁用前沿模型 judge 作校准锚点，线上采样用小模型 judge 但**必须被锚点校准**。
5. 所有阈值为结构占位，按你的任务与标注资源实测重设。
