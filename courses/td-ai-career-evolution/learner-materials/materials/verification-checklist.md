- [ ] 六个 manifest 的 `page_id`、fixture、expected 和 fault patch 一致。
- [ ] `baseline -> fault -> repair` 严格为 `0/1/0`。
- [ ] fault 改变观察值而不是 expected；AI 不充当独立 Oracle。
- [ ] Prompt、Schema、Eval、Mutation 和图均可回链。
- [ ] 组织 band、年限、阈值、晋升、薪资和就业未被课程猜测。
- [ ] 报告状态保持 `PASS-FIXTURE`，模型状态保持 `NOT_RUN`。
- [ ] 迁移到新场景时重新填写 owner、版本、分母、切片和失败动作。
