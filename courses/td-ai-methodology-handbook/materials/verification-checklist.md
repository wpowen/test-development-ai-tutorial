# 验收检查单

## 一、夹具运行（可自动验证）

- [ ] `python3 scripts/validate_handbook.py all` 退出码为 0，七道门禁全 PASS
- [ ] 五类故障各自退出码为 1
- [ ] 每类故障被**指定的那一道**门禁拦下，而不是被别的门禁顺带拦下
- [ ] `--fault none` 重新返回 0
- [ ] `--report` 生成的 JSON 含 `maturity` 与 `not_run` 四级
- [ ] 运行过程未修改 `examples/` 下任何文件（故障注入在内存中进行）

## 二、理解验收（学员自答，需能说出理由）

- [ ] 能说出为什么「只有 baseline 的绿色」不构成证据
- [ ] 能说出结构门禁与语义门禁为什么必须分开留痕
- [ ] 能说出为什么语义层不得单独放行 blocker
- [ ] 能说出冲突的正确处置是阻断加升级，而不是裁决
- [ ] 能说出 `pass@k` 与 `pass^k` 分别用于回答什么问题
- [ ] 能说出为什么 Waiver 必须有过期时间

## 三、迁移验收（用自己的业务对象）

- [ ] 已用自己的一个高风险需求填出 Test Basis Pack 与 requirement contract
- [ ] 契约中至少有一条 `UNKNOWN`，且指定了需谁确认
- [ ] 风险登记册中每条高风险有层级、方法与 Oracle 来源，理由不是工具名
- [ ] 关键条件的 Oracle 独立于被测实现，也独立于本次模型输出
- [ ] 已注入一个自己业务上的已知缺陷，并在自己的门禁上稳定变红三次
- [ ] 失败信息足以定位到五层归因中的哪一层

## 五、证据边界自查
