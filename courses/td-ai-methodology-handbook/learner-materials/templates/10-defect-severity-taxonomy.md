# 缺陷分级、分类与记录规范

## 1. Severity 与 Priority 必须是两个字段

| | 定义 | 谁决定 |
| --- | --- | --- |
| Severity | 缺陷造成的**后果**严重程度 | 测试开发（R），安全 owner（C） |
| Priority | 修复的**紧急**程度 | 产品 owner（A） |

合并这两个字段是最常见的流程缺陷：它会让"后果严重但可以下个版本修"的问题无处安放。

## 2. Severity 定义

| 级别 | 定义 | 示例 |
| --- | --- | --- |
| S1 阻断 | 不可逆资金损失、大范围数据泄露、核心链路不可用 | 已发货订单被自动退款 |
| S2 严重 | 主要功能错误、数据错误可恢复、权限越界（无泄露） | 退款金额计算错误 |
| S3 一般 | 次要功能异常、体验受损、有绕行方案 | 状态提示文案错误 |
| S4 轻微 | 文案、样式、非关键日志 | 按钮对齐 |

## 3. Priority 定义

| 级别 | 定义 |
| --- | --- |
| P0 | 立即修复，阻断发布 |
| P1 | 本版本内修复 |
| P2 | 下个版本 |
| P3 | 待排期 |

## 4. AI 系统特有缺陷分类（必须单列）

| 分类 | 定义 | 归属判定方式 |
| --- | --- | --- |
| HALLUCINATION | 输出无来源支持的事实 | source_refs 存在性 |
| UNFAITHFUL | 有证据但结论与之矛盾 | 忠实度 Oracle |
| REFUSAL_WRONG | 该答的拒答 / 该拒的回答 | 期望拒答集 |
| SCHEMA_DRIFT | 结构化输出不符契约 | Schema 校验 |
| TOOL_MISUSE | 错误工具/越界参数/越权调用 | 工具策略层 |
| NON_DETERMINISM | 结果不稳定超出约定区间 | 重复运行分布 |
| DRIFT | 同版本随时间行为变化 | 持续评估基线 |
| INJECTION | 不可信内容改变了执行 | 攻击集 |
| LEAKAGE | 跨租户/敏感字段泄露 | DLP + 授权断言 |
| COST_REGRESSION | 质量持平但成本/延迟劣化 | 单位成功成本 |

## 5. 缺陷记录必填字段

```
缺陷 ID        :
标题           : <一句话，含对象+现象+条件>
Severity       : S1/S2/S3/S4
Priority       : P0/P1/P2/P3
分类           : 传统分类 或 AI 特有分类
关联风险 ID    :
关联 run_id    :
复现步骤       :
可复现性       : N 次中复现 M 次   ← 非确定性缺陷必填，禁止写"偶现"
归属层         : L1输入数据 / L2模型Prompt / L3检索工具 / L4环境 / L5 Scorer阈值 / UNKNOWN
Oracle 依据    : <哪一层 Oracle、哪条规则判定它是错的>
影响面         :
证据路径       : <trace / 报告 / 截图>
```

## 6. 去重与聚类规则

- 允许用模型做**聚类候选**，但必须保留每条原始证据；
- 每个聚类**至少抽检 3 条**确认同因；
- 无法归类的样本进入 `UNKNOWN` 桶单独跟进；
- **`UNKNOWN` 桶不允许为了报表好看而清空。**

## 7. 缺陷逃逸台账（按月）

| 月份 | 逃逸数 | S1 | S2 | 逃逸原因分布 | 应被哪层拦下 | 补救动作 | 同类反查覆盖数 | 闭环率 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |

逃逸原因分类：未覆盖风险 / Oracle 不足 / 数据不代表 / 环境差异 / **已知但被 Waiver**
