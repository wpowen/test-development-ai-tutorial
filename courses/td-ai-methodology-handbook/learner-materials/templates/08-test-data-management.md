## 5. 污染检查

- [ ] 公开数据集已核对许可证与可能的训练污染
- [ ] 自建评测集未被写入 Prompt 示例
- [ ] holdout 未出现在任何调优流程中

## 6. 隐私红线自查

- [ ] 无未脱敏真实个人信息
- [ ] 无真实支付账号/证件号
- [ ] 无生产密钥或真实 token
- [ ] 未向不可控外部服务发送生产数据
- [ ] Prompt / 日志 / Trace / 缺陷记录中无敏感字段残留
- [ ] 假名化数据已评估准标识符组合的再识别风险
