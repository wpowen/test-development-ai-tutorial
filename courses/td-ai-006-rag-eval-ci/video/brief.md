# 视频 Brief：别再问 AI 好不好用，先让它故意失败一次

- Audience：测试开发、AI 应用工程师、质量负责人
- Duration：4–6 分钟
- Promise：拿走一个无需 API Key 的 RAG/LLM 质量门禁仓库，现场看到 PASS→FAIL→PASS。
- Hook：一个客服 AI 把“7 天退款”说成“30 天无条件退款”，你的测试能不能在合并前拦住？
- Visible proof：终端 exit code、mutation report、逐 case failure、CI 文件。
- Download：完整 `lab/`、评测集、evaluator、mutation、报告和 reusable Skill。
- Boundary：录制输出只验证评测 harness；真实模型必须另做 live run。
