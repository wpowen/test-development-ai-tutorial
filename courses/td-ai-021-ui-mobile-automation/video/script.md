# 讲解脚本

1. **cold-open-failure**：显示 `missing_contracts`，问“按钮还能点，为什么门禁必须失败？”
2. **stakes-and-promise**：说明 locator 与业务 oracle 分工，交付一组跨平台样例和离线证据。
3. **before-after**：对比坐标点击/模型自报通过与语义 locator/确定性 oracle。
4. **plain-mental-model**：把 locator 讲成地址，把 oracle 讲成验收单。
5. **guided-demo**：运行 baseline，打开 JSON，再运行 mutation。
6. **failure-diagnosis**：让 learner 预测两个缺失字段，再核对报告。
7. **learner-practice**：把契约改成搜索空结果，并写第二个断言。
8. **transfer-challenge**：加入权限拒绝场景，必须改变数据与平台标识。
9. **artifact-handoff**：交付 examples、matrix、runbook、报告和明确的 NOT_RUN 边界。
