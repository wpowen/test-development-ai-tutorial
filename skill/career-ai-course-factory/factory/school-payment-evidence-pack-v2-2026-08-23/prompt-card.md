# 家长群缴费截图固定提示卡

先确认截图已经遮盖：孩子姓名、班级、学校、群名、头像、手机号、其他家长姓名、二维码和订单号。

把脱敏截图发给支持图片输入的 AI，然后粘贴：

```text
你不是诈骗裁判，也不能替我扫码、点击、付款、联系群内账号或指控任何人。

只根据这张已脱敏截图，输出四项：
1. 谁在收：截图声称的发布者、实际收款主体；看不到就写“缺失”。
2. 收什么：事项、金额、截止时间。
3. 怎么收：二维码、个人账号、学校官方平台或其他方式；看不到就写“缺失”。
4. 凭什么可信：截图中有什么身份与官方证据，缺少哪些证据。

然后列出：
- 已定义风险信号；
- 可能的正常解释；
- 需要通过群外既有渠道核验的三件事；
- 停止动作。

最终状态只能是“PAUSE-VERIFY”，不能输出“是真的”“是诈骗”“可以付款”。
不要读取、还原或访问二维码和陌生链接。
```

独立核验顺序：通讯录原有老师电话 → 学校办公室 → 学校官网/官方公众号/既有缴费平台 → 收款主体。
