## Competitor observations

直接课程页显示，海外供给已经覆盖 LLM eval、TDD、mutation、pytest、安全与 CI；中文供给偏“全套教程/全栈智能体/资料包”表达。公开页面很少同时展示可下载离线夹具、故障注入前后报告、版本化适配器和从业者复核。该判断限于 C01-C10 样本，不代表全市场统计。

## Vendor claims

- S17、S19 及部分 Bilibili 课程页中的“全套”“效率倍数”“准确率”等属于营销声明，未作为课程有效性的证据。
- Promptfoo、DeepEval、LangSmith 的能力来自官方产品文档；它们能支持某种评测，不代表默认配置适合每个项目。

## Inference

1. 测试开发的差异化 AI 课程应以“质量定义 + 可复现执行 + 故障证明 + 工程门禁”为统一骨架。
2. 首课应选择测试 AI 系统，而非再做普通需求到测试用例，因为前者的 AI 中心性更高，也更符合用户反馈。
3. 离线 snapshot 是降低入门成本的教学适配器；真实模型质量结论必须另做 live run。
4. 20 课路线应把工具品牌放在适配层，把数据集、指标、轨迹、阈值和人工决策作为稳定能力。

## Unknown

- 这些课程的真实完成率、付费转化、学员就业或生产效率没有公开一致数据。
- 当前未获得企业测试开发的真实脱敏 RAG/Agent 项目与评审意见。
- 当前未使用付费模型 API 复测各供应商输出，因此不比较模型优劣。
- 课程中建议阈值是教学夹具门禁，不是行业统一标准。
