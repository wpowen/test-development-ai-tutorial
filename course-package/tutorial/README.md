# 测试开发 × AI 菜鸟式教程

这不是一本需要从头读到尾的长文档，而是一套可以按知识树逐页学习的教程。

## 如何学习

打开 `index.html` 后，左侧是完整课程目录。每一页只解决一个问题，并显示：

- 你现在学到哪里；
- 本页学完能做什么；
- 需要先学哪些页面；
- 这个知识和测试开发工作有什么关系；
- 最小例子；
- 自己动手的步骤；
- 预期结果；
- 常见错误；
- 完成检查；
- 上一页和下一页。

可以按默认路线逐页学习，也可以通过搜索直接找到“RAG”“Agent 轨迹”“Prompt injection”“CI”等主题。页面完成状态保存在当前浏览器中。

## 教程结构

教程分为五个模块：

1. 先建立共同语言：理解 AI 系统和传统软件在测试上的不同；
2. AI 帮你做传统测试：风险、测试生成、边界数据和失败归因；
3. 测试 LLM 和 RAG：评测样例、检索、引用、忠实性、拒答和 judge；
4. 测试 Agent：结果、动作、轨迹、工具、权限、安全和自愈；
5. 建设 AI 质量系统：CI、版本、Trace、成本、漂移和 Capstone。

页面类型包括概念页、跟做页、诊断页、参考页和项目页。概念页负责听懂，跟做页负责第一次成功，诊断页负责出错后会查，项目页负责独立完成职业任务。

## 与后台研究的关系

教程页面来自职业工作域、业务场景和知识依赖，不按工具品牌堆砌。后台来源账本、竞品矩阵和 JSON 用于保证课程可更新、可追溯；普通学习者不需要先阅读这些文件。

当工具或模型更新时，教程的稳定知识树不变，只更新对应参考页、工具适配器、版本说明和可运行证据。
