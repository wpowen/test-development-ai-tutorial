# 检查单 04：自动化用例合并（S7）

> 五条门槛全部满足才允许合并。

- [ ] 在预埋缺陷上稳定变红（连续 ≥3 次）
- [ ] 在干净基线上稳定变绿（连续 ≥3 次）
- [ ] 失败信息足以定位到层（输入数据 / 模型 Prompt / 检索工具 / 环境 / Scorer 阈值）
- [ ] 运行时间在其所属层级的预算内
- [ ] 不依赖执行顺序、不依赖上次残留状态

## 附加检查

- [ ] 断言检查的是业务结果，不只是"元素可见"或"状态码 200"
- [ ] 用例绑定了 risk id 与 Oracle 来源
- [ ] 没有为了通过而加长超时或增加 retry
- [ ] 外部依赖按策略处理（真实 / 沙箱 / 录制回放 / Mock），且已记录
- [ ] 模型调用默认走录制回放；若用真实调用，已声明为独立层
- [ ] 测试数据在用例内自建自清，不污染共享环境

## Flaky 处理

- [ ] 连续 5 次中出现 ≥1 次非确定性失败 → 标记 `QUARANTINE`
- [ ] `QUARANTINE` 用例移出阻断集但**保留运行并统计**
- [ ] 未通过删除或加 retry 掩盖 Flaky
