# 检查单 07：安全与隐私

## 信任边界
- [ ] 用户输入、检索内容、工具返回值、模型输出均按不可信处理
- [ ] 授权在**模型之外**完整中介（身份→租户→scope→参数→幂等→审批）
- [ ] 输出 DLP 存在，但未被当作授权的替代

## 攻击面
- [ ] 直接注入已测
- [ ] **间接注入**已测（网页、邮件、知识库、工具返回、文件名）
- [ ] 工具/MCP 描述被篡改的场景已测
- [ ] 越权调用（未验证身份即可写）已测
- [ ] 跨租户读取已测；任一次出现即 blocker
- [ ] 敏感泄露已测（输出、日志、Trace 三处）
- [ ] 过度代理权已评估（是否具备超出任务的可写工具）
- [ ] 委托链：权限不随 Handoff 扩大
- [ ] 长期 Memory 污染已测
- [ ] 语义缓存投毒已测
- [ ] 依赖与模型来源已固定版本

## 期望结果的精度
- [ ] 每条攻击载荷的期望结果写明**被哪一层拦下**
- [ ] 报告分别统计"模型拒绝"与"授权层拒绝"

## 隐私红线
- [ ] 无未脱敏真实个人信息
- [ ] 无真实支付账号 / 银行卡 / 证件号
- [ ] 无生产密钥或真实 token
- [ ] 未向不可控外部服务发送生产数据
- [ ] Prompt / 日志 / Trace / 缺陷记录无敏感字段残留
- [ ] 假名化数据已评估准标识符再识别风险
- [ ] 每个数据集有授权人、保留期、销毁方式与责任人

## 高风险场景（涉及资金/权限/专业建议/未成年人/不可逆对外动作）
- [ ] 有人工确认环节，且确认信息足以让人判断
- [ ] 有能力沙箱，最大损失有明确上限
- [ ] 有独立于模型的规则 Oracle（L5 不单独放行）
- [ ] 回滚与对账已演练

## 确认疲劳
- [ ] 单任务人工确认次数在可接受范围
- [ ] 确认信息含对象、金额、影响面、不可逆性
- [ ] 确认框默认选项是安全选项
- [ ] 不存在"全部同意"绕过逐项判断
- [ ] 已做连续任务下的确认正确率变化实验

## 审计留痕
- [ ] 门禁结果、Waiver、阈值变更、holdout 开封、生产写权限授予、数据授权与销毁、安全例外，全部留痕且不可静默修改
