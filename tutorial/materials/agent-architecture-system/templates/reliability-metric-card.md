# 可靠性 Metric Card

> 任何 `pass^k` 结论都必须附这张卡片，否则不可复用，也不能进发布决定书。

```
指标名          : <pass^5（每次都成功）>
口径            : 经验口径 |{sᵢ = k}| / n     ← 或解析口径 p^k，必须写明是哪一个
分子 / 分母     : <每次都成功的任务数> / <任务总数>
k               : <5>          P0 建议更大的 k，P2 可较小
状态重置规则    : <每次 run 前重置到快照 id>
区间方法        : Wilson，置信度 95%
聚类单位        : task          ← 不是 run；n×k 会严重低估不确定性
CI              : [<下界>, <上界>]
样本量理由      : <为什么这个 n 足够 / 不足够>
时长桶          : <桶定义与每桶 pass^k>
切片            : <切片列表，标出哪些是 blocker>
四维版本        : 模型 <> / prompt <> / 工具清单 <> / 记忆快照 <>
temperature     : <值>（固定并记录）
owner           : <姓名/角色>
失败动作        : <阻断 / 降级 / 转人工 / 限流>
```

## 同时必须报告的伴随数字

```
pass@k          : <值>    ← 与 pass^k 一起报，不能只报一个
首错位置分布    : <span → 次数>
成本 P99        : <值>
单位成功成本    : <值>
```

## 三条纪律

1. **承诺基于 `pass^k`**，`pass@k` 只说明能力上限。
2. **样本不足时结论是 `EVIDENCE-INSUFFICIENT`**，不是通过。
3. **失败 run 不得删除**；分布好看不是目标。
